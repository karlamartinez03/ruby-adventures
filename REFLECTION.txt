Part 1: My solution is very similar to Paul's. The main difference
is that the official implicit-self step already adds the empty parentheses, so it
ends up identical to the implicit-parens step. Mine saves the parentheses for the
next step, so each step removes exactly one kind of sugar. The official operators
step also wraps the first string in parentheses, which makes the
((a + b) + c) + d structure easier to see.

Part 2: All three loopless methods use the same approach as the official solution.
The only differences are in spacing. The official alternative for
build_credits uses sort_by with find_index. I'd avoided that approach because
sort_by isn't guaranteed to be stable, but when I tested it, it matched the
original on every case. Still, flat_map seems more direct to me. The biggest
takeaway was seeing how each loop pattern maps onto select, map, or flat_map.
